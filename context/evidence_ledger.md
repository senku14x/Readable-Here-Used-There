# TCSIF evidence ledger (2026-09-07; §E maintained to 2026-09-24)

One consolidated matrix of every load-bearing finding, calibrated to the evidence ladder. Companion to `context/h1_stopping_point.md` (the eight prose verdicts) and `context/project_status_2026-09-07.md` (full numbers). **All findings are on Qwen3.6-27B (`6a9e13bd`), teacher-forced copy/direct organisms, readouts at interior carrier positions, windows L48–50 & L51–59.** Instruments: **J_NP** (Neuronpedia J-lens, primary), **RESID_P** (plain-sentence axis), **LOGITS** (model output), J_CB/R_CB (robustness subset). Agreement across instruments on the same forwards is **robustness, not independent samples**. **Nothing here is about behavior (H3) or a maintenance mechanism (H2).**

**Evidence ladder:** Observation → Recurring pattern → Supported empirical claim (survives relevant controls/baselines) → **Causal claim** (targeted intervention changes outcome; nonspecific perturbation/degradation ruled out) → **Mechanistic** (causal account of *how*, distinguished from competing mechanisms). "Extension scale" = fewer/shared identities than the registered evaluation banks.

## B. Not established (open / negative)

- **H3 — behavioral use (started; see row 14).** The first experiment finds a **dissociation**, not a clean behavioral use: the H1 transplant that redirects the internal readout ~0.76 moves the consumer's answer only ~0.2 of the clean separation, and that residual shift is only partly target-specific with an unidentified route. So content whose *readability* is causally redirected is **not shown to be behaviorally used** on this consumer. Still open: a consumer whose answer cannot re-read the visible instruction (computed-sum / category-member codebook) to isolate the carrier route.
- **H2 — maintenance mechanism.** What holds content across the carrier (source K/V, GatedDeltaNet recurrent state, re-retrieval) is untested; the hybrid complete-state parity control is a prerequisite. **Not started.**
- **Read-site component** of selection (localization Step 2). Designed, not run.
- **Individual-member representation** from category labels (only member readability, #9).
- **Selection without the copy bridge / tag head** (pure direct organism) — designed (`scaffold_generality/single`), not run.
- **Cross-model generality** — one model only.

## C. Methodological record (amendments, corrections, earned mistakes)

Every scored gate that failed was repaired and re-run; nothing scored was deleted. Corrections on record:
- **RMSNorm gain is `1+weight`** in this architecture (a float32 diagnostic scaled ~½ before it was caught).
- A stage-name check dropped RESID_P from an orthopanel run (arrays kept, stage re-run).
- The plain-axis fitter matched the first substring (`"king"` in `"asking"`); fixed to the template slot.
- Package 1 windows amended (L51–59 promoted to co-primary) before any Package 2 forward.
- **Localization Amendment 1** (external review): the cross-arm source-token stage was withdrawn — sources precede the tag, so their states are arm-invariant (predetermined no-op); the source-side-tag account is architecturally excluded.
- **Localization Amendment 3** (external review): the patched "instruction region" had included the **user-side carrier + delimiters** (the copy organism repeats the carrier in the user turn); the corrected `region_split` isolated the effect to the instruction tokens (tag-dominant; user carrier negligible) — the original claim was uncontrolled, the correction made it stronger.
- **early_late_mapping Amendment 1** (external review): added a length/structure-matched `early_unusable` control so a raw X drop can't be a generic long-prefix effect; it was load-bearing.
